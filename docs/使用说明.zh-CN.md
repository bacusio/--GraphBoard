# 关系图谱白板 v0.4.0 使用说明

## 快速开始

### Windows 版本

1. 打开 `windows/`。
2. 双击 `GraphBoard.exe`。
3. 保持启动窗口开启，浏览器会打开本地白板。
4. 如果浏览器没有自动打开，复制启动窗口中的 `http://127.0.0.1:<端口>/` 地址到浏览器。
5. 关闭启动窗口即可停止本地服务。

### 网页部署版

将 `web/` 上传到 GitHub Pages、Cloudflare Pages、Netlify 或其他静态托管服务。也可以用任意本地静态服务器提供该目录。

### WebGL 增强版

将 `webgl/` 作为独立静态站点部署。它使用 WebGL 绘制背景网格，关系、节点和编辑交互仍由现有 SVG 层处理；如果浏览器不支持 WebGL，会自动保留普通背景。

## 基本操作

- 导入：点击“导入”，或把 PNG/JPG/WebP/GIF 拖入画布。
- 改名：选中对象，在右侧“名称”输入框修改；双击名称也可直接聚焦。
- 移动：拖动对象；磁吸默认开启，按住 `Alt` 可暂时关闭。
- 建立关系：从对象边缘的小圆点拖向另一个对象。
- 删除：选中对象后按 `Delete` 或 `X`。
- 保存/打开：使用“保存项目”和“打开项目”，项目文件扩展名为 `.graphboard.json`。
- 导出：点击“导出 PNG”。

## 时间切片

- 顶部“时期”菜单用于切换当前时期。
- 选择“＋新增时期…”可以新增 2025、2026 等时期。
- 选中对象后，头像右侧的 `＋` tag 可以为该对象新增时期。
- 已设置时期的对象会在头像右侧显示年份数字。

## 三角对象

“三角对象”可用于事件、作品、舞台、项目或中介节点。选中一个圆形对象后创建三角对象，三角对象会默认锁定并跟随圆形对象移动。三角对象也可以通过白色箭头连接任何对象。

## 排版

- 按阵营对齐：默认模式，保持阵营关系。
- 按范畴层次：根据有向关系排列迭代层级。
- 以选中对象为中心：显示一阶、二阶和外围关系。
- 保持手工布局：只整理明显重叠，不重排整体结构。

## 示例图库

画布底部的“示例”栏提供八类预填充关系图：公司协作、人物关系、学术谱系、供应链、知识体系、软件依赖、工作流程和分类映射。点击示例按钮会载入对象、关系和阵营名称，可直接观察或继续编辑。示例 PNG 位于 `examples/` 目录。

## 快捷键

`V` 选择，`G` 移动模式，`R` 关系模式，`F` 全览，`Esc` 取消，`Delete/X` 删除，`Ctrl+Z` 撤销，`Ctrl+Y` 重做。

## 隐私与故障排查

项目数据默认只保存在本机浏览器中。Windows 启动器只绑定 `127.0.0.1`。如果浏览器启动失败，服务仍会继续运行；请复制本地地址访问，并查看 `GraphBoard-launcher.log`。
